Privacy Policy

GSC Analytics is a personal application for analyzing Google Search Console data.

Information Accessed

The application requests read-only access to Search Console properties and performance data through Google's OAuth 2.0 authorization.

Use of Information

Data is used to analyze website search performance, including clicks, impressions, search queries, and average positions.

Data Storage

OAuth credentials and retrieved data may be stored locally for the application's operation.

Data Sharing

The application does not sell Google user data.

Revoking Access

Users can revoke access through their Google Account security settings.
